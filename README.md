# Behance → IDM 安装包

本仓库只存放可下载的安装包、校验文件和使用说明。开发源码在独立私有仓库维护。本工具为个人开发，非 Adobe、Behance 或 IDM 官方产品。

## 下载

[下载 Windows 安装包 v1.1.3](./behance-idm-helper-1.1.3-windows.zip?raw=true)

[查看 SHA-256 校验值](./SHA256SUMS.txt)

这是 ZIP 安装包，包含 Chrome 扩展、本地助手、安装脚本和 comtypes 运行依赖，并非独立 EXE。安装包内的 JavaScript/Python 代码可以查看。

## 首次安装

1. 安装 Chrome、Python 3.10 或更新版本（建议 3.12）、具有适用授权的 IDM。启动 IDM 一次。
2. 下载 ZIP，解压到固定目录。
3. 双击 `install.cmd`，注册本地助手；完整包已附带依赖。无需管理员权限。
4. Chrome 打开 `chrome://extensions/`，开启开发者模式，点击“加载已解压的扩展程序”，选择包内 `extension` 文件夹。
5. 打开 Behance 作品页面，在 Adobe 视频左上角点击“用 IDM 下载”，查看实际画面尺寸，再在 IDM 中开始下载。

保留原 IDM Integration Module。此助手不包含 IDM 软件或注册码，不转移 IDM 授权。

## 手动升级

本工具不自动检查或安装更新。

1. 在此仓库下载新版本。
2. 备份旧助手文件夹，将新文件覆盖到原安装目录。
3. 运行 `install.cmd`，重新生成适合本机的配置。
4. 在 Chrome 扩展页面重新加载本助手，再刷新已打开的视频页面。

原安装目录请在 Chrome 扩展详情中确认；如果首次安装使用中文目录名称，仍覆盖原目录即可，无需改名。若回退，请恢复备份、运行备份中的安装脚本并重新加载扩展。

## 范围与限制

- Windows + Chrome + IDM。
- 支持提供可访问 MP4 的 Adobe Creative Cloud 视频，不能保证所有 Behance 视频都适用。
- 不处理 DRM；只提供 HLS 或使用其他播放器的作品可能不支持。
- 沿用 Windows 系统代理。
- 未上架扩展商店。IDM 官方对商店第三方扩展使用其接口有限制，本包仅提供本地安装方式。
